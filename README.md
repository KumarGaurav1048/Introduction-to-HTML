## Project: Leetcode Techno Contest 2026

A single-page website for a fictional coding contest and tech event. It was built in three stages to show how a page grows from plain structure to a styled design.

| File | Stage | Description |
|------|-------|-------------|
| `01_page.html` | Structure | Plain HTML with semantic sections, no styling |
| `02_page.html` | Styling | Adds CSS for layout, colours and typography |
| `03_page.html` | Final | Cleaned-up version with tidy markup (recommended) |

### Features

- Green header with event title and tagline
- Dark navigation bar with anchor links that jump to each section
- **About** section describing the event
- **Schedule** table with times, sessions and speakers
- **Speakers** list with names and roles
- **Contact** form with name, email and message fields
- Card-style sections with hover shadow effect
- Styled form inputs with focus and button hover/active states
- Responsive viewport setup for mobile screens

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/KumarGaurav1048/Introduction-to-HTML.git
   ```
2. Open the folder in VS Code.
3. Open `03_page.html` in your browser, or right-click it in VS Code and choose **Open with Live Server** if you have that extension installed.

No installation or build step is needed.
